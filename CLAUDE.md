# Dream Pinball

Read `AGENTS.md`, `architecture.md`, and `TODO.md` before changing code. Follow `AGENTS.md` as the shared project standard.

## Claude Code responsibilities

- Explain proposed behavior before a large implementation.
- Keep solutions understandable to a parent-and-child development team.
- Preserve the established architecture and naming conventions.
- Prefer small, independently testable features.
- Do not add dependencies without approval.
- Provide exact Roblox Studio playtest instructions after code changes.
- Do not claim a feature works until it has been tested in Studio.

## Review mode

When asked to review another agent's work:

- Do not modify files unless explicitly instructed.
- Prioritize functional bugs, exploit risks, state synchronization problems, and regressions.
- Reference exact files and functions.
- Skip findings that are purely stylistic.
